# 🎓 Информационная система "Приемная комиссия"

Современная система автоматизации работы приемной комиссии учебного заведения на C# с использованием Windows Forms и SQLite.

## ✨ Возможности

### Для абитуриентов
- 📝 Регистрация и авторизация в системе
- 🔍 Просмотр доступных специальностей
- 📋 Подача заявлений на поступление
- 📊 Отслеживание статуса заявлений
- ✏️ Управление своими заявлениями

### Для администраторов
- 👥 Управление пользователями
- 🎓 Управление специальностями (добавление, редактирование, удаление)
- 📋 Обработка заявлений (одобрение, отклонение)
- 📈 Просмотр всех заявлений и статистики

## 🚀 Быстрый старт

### Требования
- Windows 7 и выше
- .NET 6.0 Runtime или выше
- 50 МБ свободного места
- 1 ГБ оперативной памяти

### Установка и запуск

1. **Скачайте проект** на компьютер или флешку
2. **Соберите проект** (если нужно):
   ```
   Запустите: Build.bat (или Сборка.bat)
   ```
3. **Запустите программу**:
   ```
   Запустите: Run.bat (или Запуск.bat)
   ```

> **Примечание:** Доступны как английские (Build.bat, Run.bat), так и русские версии батников.

## 🗄️ База данных

Система использует **SQLite** - встроенную файловую базу данных.

- Файл БД: `admission.db`
- Местоположение: папка с программой
- Портируемость: ✅ Да (копируется вместе с программой)
- Резервные копии: Просто скопируйте файл `admission.db`

### Структура БД

**Таблицы:**
- `Users` - пользователи системы
- `Specialties` - специальности учебного заведения
- `Applications` - заявления абитуриентов

## 📝 Разработка

### Открытие проекта в Visual Studio

1. Откройте Visual Studio 2022 или новее
2. Выберите: File → Open → Project/Solution
3. Откройте файл `AdmissionSystem/AdmissionSystem.csproj`
4. Нажмите F5 для запуска

### Пакеты NuGet

- `System.Data.SQLite.Core` - работа с SQLite
- `Dapper` - легковесный ORM
